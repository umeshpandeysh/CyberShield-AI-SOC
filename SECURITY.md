# Security Policy

## Supported Versions

We actively support and patch the following versions of **CyberShield-AI-SOC**:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We take the security of CyberShield-AI-SOC seriously. If you believe you have found a security vulnerability, please report it immediately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please follow these steps:
1. Email your findings to **security@cybershield-soc.io** (or contact the project owner directly).
2. Include a detailed description of the vulnerability, steps to reproduce, and any potential exploits or proof of concept (PoC).
3. If possible, encrypt your email using our PGP key (details available upon request).

## Our Response Process

* **Acknowledgement**: We will acknowledge receipt of your report within 24 hours.
* **Triage**: Our security response team will investigate and triage the issue within 72 hours.
* **Fix & Release**: We will work on a fix and release a patched version or write a workaround as quickly as possible, generally aiming for a release within 14 days.
* **Disclosure**: We will coordinate the public disclosure of the vulnerability with you to ensure users have time to patch their systems before full details are public.

## Safe Harbor

We support responsible security research. If you make a good faith effort to comply with this policy during your research, we will not initiate legal action or complain to law enforcement regarding your research.
